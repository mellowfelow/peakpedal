## 1. Technical audit (static)

**Build & crosscheck: clean.** 231 pages generated, zero build errors. Crosscheck: 31 pass, 0 fail. The one warning (`FORMS.provider is "smtp"` needs env vars) is expected pre-configuration language, not a live problem — SMTP env vars are confirmed set in Vercel per the prior audit's close-out.

**Confirmed fixed since 2026-09-08 audit** (all previously flagged issues):
- ✅ H7 — `shippingDetails` + `hasMerchantReturnPolicy` now present on every Product Offer (`src/app/products/[slug]/page.jsx`).
- ✅ H3 — OG/Twitter default image is a real 1200×630 PNG (`og-default.png`), not `placeholder.svg`.
- ✅ H4 — Product pages carry per-product OG/Twitter images (`product.images[0]`), no fallback to the site default.
- ✅ H5 — Product "thin content" fixed properly, not just padded: `productLongCopy()` composes real per-product variation from motor-family blurbs (13-way lookup table), travel-bracket commentary, and brand price-positioning — genuinely unique paragraphs per SKU, not a find/replace template. Verified no duplicate-content risk.
- ✅ M15 — `docs/PROJECT.md` now correctly states 124 SKUs + Tawk widget (was stale at last audit).
- ✅ M12 — Organization/Store schema, brand descriptions, and llms.txt all carry real, differentiated brand facts (16 brands each with real description text).

**New finding — CLAUDE.md is now stale (not PROJECT.md this time):**
`CLAUDE.md` Architecture section still says `PRODUCTS` (78 SKUs). Actual catalog is **124 products + 33 accessories** (confirmed via direct import). Low severity (doesn't affect the live site, only Claude Code's own context), but worth a one-line fix since CLAUDE.md is read on every session and gives an incorrect scale signal.

**New finding — no AVIF, WebP-only:**
`scripts/images.mjs` emits `.webp` only (0 `.avif` files across 160 images). This is a deliberate, documented tradeoff (`next.config.mjs` disables `next/image` optimisation entirely because the Vercel Hobby transform quota caused HTTP 402s in production — fixed at the last audit by serving raw pre-built webp). Since images are already hand-optimised and served as plain `<img>` tags, adding a pre-built AVIF `<picture>` source would cost no runtime optimizer budget and would shave ~20-30% off the largest product photos (several are 148-228KB). **Optional, not urgent** — the current setup is stable and was chosen specifically to fix a worse production bug.

**Sitemap:** single `sitemap.xml` (217 URLs) rather than a split index — a documented, reasonable call given it's well under the 50k-URL split threshold. `lastModified` is stamped `now()` on every build for most static/category/product pages rather than tracking real content-change dates, which slightly overstates freshness signals to crawlers but isn't a functional bug.

**robots.txt:** clean — all major AI crawlers allowed, `Content-Signal` directive present, correct disallow list (`/cart/`, `/search/`, `/order/`, thank-you pages, `/api/`, `/_next/`). No accidental blocking of indexable pages.

**Agent-ready files:** all A–N files present and valid per crosscheck (`llms.txt`, `auth.md`, all 8 `.well-known/*` endpoints, `webmcp.js`, Link header). `llms.txt` correctly follows llmstxt.org markdown-link spec, not bare bullets.

**Accessibility basics:** skip-link present, `<main id="main">` landmark, single `<h1>` on all 223 prerendered pages (crosscheck-verified), descriptive alt text and explicit `width`/`height` on product images (CLS-safe).

## 4. Field data — Semrush

| Metric | Value |
|---|---|

| Organic keywords (UK db) | 532 |

| Backlinks | 76 (+69% recent) |

**532 keywords ranking in the UK** — consistent with the content depth (124 products + 33 category pages + 17 blog posts), all clustered in positions 24–56 (page 3–6) with low Keyword Difficulty (8–26%). This matches GSC's ~44 average position exactly — independent confirmation, not a new number.

**Important finding — the "64 referring domains / 76 backlinks" are not real backlinks. They're spam-directory noise, not something anyone at Peak Pedal did.**

Inspected the actual backlink list (not just the summary count) — every single source is a link-farm / SEO-spam page, not a genuine citation:
- `fiverr-seo-for-small-businesses.site` — an auto-generated page advertising Fiverr SEO gigs, name-dropping peakpedal.org in the pitch text
- `best-seo-domains.com`, `backlink-top.shop`, `beauty-care-shop.shop`, `agentbetting.online` — link-farm / PBN pages that mass-list random domains to look "active" and sell backlink packages
- `8pw.ru`, `8coint.com` — Russian redirector/directory spam
- Anchor text is literally SEO-services ad copy ("Proven White Hat SEO Links for peakpedal.org to Raise Domain Rating", "With Fiverr's niche edits, peakpedal.org's visitors doubled from 3K to 6K monthly ⭐") — these domains were never actually driving traffic; the text is templated marketing copy that happens to mention the domain.
- 98% of the 64 referring domains score 0–10 Authority Score (i.e., worthless). 45% are already `nofollow`. TLD mix is dominated by `.shop`/`.site` (50% combined) — the classic footprint of automated spam-directory crawlers, not a deliberate negative-SEO attack or a purchased link package.

**This is not hurting the site** — Google already discounts zero-authority spam domains automatically, and it's Google's own explanation for GSC's ranking behaviour (position ~44 tracks keyword difficulty vs. domain authority, not this noise) — but it also isn't helping, and it's not a substitute for the real backlink-building work flagged below. **No disavow action needed** at this volume/quality (disavowing is for cases risking a manual action, and 0-DR nofollow spam isn't that) — just don't mistake this Semrush count for real progress on the authority problem, and don't pay for any "SEO gig"/guest-posting package that promises links like these — they're exactly what's already arriving here for free and worthless.

## Priority fix list

1. **CLAUDE.md SKU count** — one-line fix, `78 SKUs` → `124 SKUs` (and note accessories separately). Trivial, do anytime.
2. **GSC: Request Indexing** on the remaining 19 "discovered — not indexed" URLs now that internal linking has improved (was 53, should convert faster this round).
3. **Optional: AVIF pass** on product images — meaningful file-size win, no risk to the Vercel Hobby quota fix since it doesn't touch `next/image`.
4. **Off-site (the real ceiling, not code):** 0 real backlinks confirmed across all three tools — GSC, Bing, and Semrush (Semrush's 64/76 count is spam-directory noise, not genuine links — see Section 4). No amount of further on-page work moves average position off ~44 without real external links/citations. This was flagged last audit and remains the single highest-leverage next step — directory listings, brand dealer-locator pages, review-site outreach, real social profiles (llms.txt/schema `sameAs` is still empty — first real profile created would unlock that field truthfully). **Do not buy backlink/guest-posting packages** — Section 4 shows exactly what that junk looks like already arriving for free.
5. **Consider Google Merchant Center** — free Shopping tab listing flagged directly by GSC, independent of organic SEO work.

Nothing in this audit rises to "broken" — the site is technically clean, previous fixes held, and indexing is trending in the right direction. The gap between technical health and ranking is entirely explained by domain authority, consistent with both GSC and Bing's own diagnosis.
